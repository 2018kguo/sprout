# Sprout

Skeleton on the left, drafts grow on the right. Uses your logged-in `claude` / `codex` CLIs (your plan, no API keys).
React + shadcn/ui + Tailwind, bundled by Bun (no Vite).

    bun install
    bun dev        # http://localhost:4747, hot reload; posts + settings in ~/.sprout/sprout.db (SQLite)

Keys: Enter new line, Tab keep, Esc toss, Cmd+Enter another take, Cmd+K refine, Alt+, / Alt+. flip takes, `#` heading.
Paste a multi-line outline to draft it all at once. Select draft text to ban a phrase.
